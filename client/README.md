# RepoLens Client

Next.js frontend for **RepoLens**.

For full project setup, architecture, and environment configuration, see the root [README.md](../README.md).

## Scripts

```bash
npm install
npm run dev      # Start development server on http://localhost:3000
npm run build    # Build production bundle
npm run start    # Start production server
npm run lint     # Run ESLint
```
